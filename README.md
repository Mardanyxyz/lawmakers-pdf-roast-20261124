A single satirical sentence for the make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert". It sets up a committee chair writing the law that will govern artificial intelligence, then undercuts that authority with the one file format he cannot handle himself: he emailed his aide a Word file named FINAL_final_REALLYFINAL and asked her to turn it into a PDF.

## Run it

```sh
node main.ts
```

This validates the sentence (one sentence, 1–320 characters) and writes it, with no trailing newline, to `/output/entry.txt`.
